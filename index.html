Teacher / setup

How this free version works: card edits are saved in the browser where you make them. To share a deck with students, export the deck JSON and publish it with the app (or have students import it). Student progress stays in each student's browser and is not visible to the teacher.

Audio help

For text-to-speech, use the speech button on a card when available. Pronunciation varies by browser and device; for Ancient Greek, uploaded recordings are usually more reliable. The browser's built-in speech feature may not support Ancient Greek correctly.
